# Wilventory WBS, edición red local

Sistema de gestión para mayoristas y distribuidoras: inventario, facturación y cuentas, instalado en la propia empresa. Los datos quedan en una PC de la empresa y las demás computadoras de la misma red se conectan a ella.

Las versiones están en [Releases](https://github.com/wdefarias16/Wilventory-WBS-Local-Releases/releases). Para instalar, descargue `Wilventory-WBS-Local-Setup-<versión>.exe` de la última versión.

Este repositorio solo contiene los instaladores y los archivos de las actualizaciones automáticas. Los programas ya instalados se actualizan solos.
